# 浮译 · Float Translate

一个轻量的 Windows 桌面翻译软件。平时常驻托盘，划词或框选时只显示鼠标附近的小浮窗。完整窗口用于设置，也提供手动翻译和历史记录入口。

## 开始使用

1. 将压缩包解压到一个固定文件夹。
2. 双击 `FloatTranslate.exe`。首次使用会打开设置页。
3. 填写 **API 地址、API Key、文字模型**，需要框选时填写支持图片输入的 **视觉模型**。
4. 点击 **测试连接**，确认能收到模型回复，再点击 **保存并应用**。测试连接会调用一次你的模型，按服务商规则计费。
5. 关闭设置窗口，软件会留在系统托盘里。

后续启动默认直接进入托盘。双击托盘图标或右键选择“打开设置”来打开完整窗口。退出请使用托盘菜单的“退出浮译”。

## 翻译方式

| 操作 | 默认快捷键 | 结果 |
| --- | --- | --- |
| 在目标程序选中文字，松开组合键 | Ctrl + Alt + T | 鼠标附近出现小浮窗，主程序保持隐藏 |
| 框选屏幕上的文字 | Ctrl + Alt + S | 拖动选区，松开鼠标后在小浮窗中显示译文 |
| 取消框选 | Esc | 关闭框选遮罩 |
| 手动翻译 | Ctrl + Enter | 在完整窗口的翻译页处理输入内容 |

选词浮窗默认约 **400 × 220 个逻辑像素**。软件先根据原文长度调整窗口，收到译文后再根据实际内容、段落和换行调整宽高。长文本会逐步使用约 500、620、740 的宽度，自动高度最大约 820，同时限制在当前屏幕的可用范围内；超出空间的完整译文可通过滚动查看。

可以拖动 **窗口任意边缘、四角或右下角的缩放手柄** 手动调整大小。手动调整后，本次浮窗会保留你选的尺寸，译文返回和重试不会自动把窗口缩回去；点击底部出现的 **自适应** 可恢复自动调整。下一次划词会重新按新文本计算大小。

它不会主动抢走目标程序的焦点。拖动顶部标题栏（包括空白区域）可移动窗口。可复制译文、展开原文、切换置顶、关闭或重试。读取失败、API 出错和未配置时也只用小浮窗提示，不自动弹出完整程序。

截图浮窗初始宽度为 440 个逻辑像素，识别出译文后同样按文本自动调整，也支持手动缩放。截图只留在本次请求的内存中，不保存为文件，也不写入历史记录。

选词读取通过系统复制功能完成，适用于支持复制的文本控件。软件会尝试恢复原剪贴板，并避免覆盖读取过程中后来发生的剪贴板更新。图片中的文字、受保护内容，以及比本软件权限更高的程序，可使用框选翻译。部分受保护或特殊渲染内容无法被截图。

## API 配置

软件使用 **OpenAI 兼容的 Chat Completions 协议**。兼容此协议的云服务、代理网关和本地模型服务均可配置。原生 Anthropic Messages、Gemini GenerateContent 和 Responses 接口需要先转换为兼容接口。

- **API 地址**：可填服务商给出的基础地址（例如 `https://api.openai.com/v1`），也可填完整的 `/chat/completions` 地址。基础地址会自动补上 `/chat/completions`。
- **API Key**：服务商提供的密钥，通过 `Authorization: Bearer ...` 发送。本地免鉴权服务可留空。
- **文字模型**：精确填写服务商列出的模型 ID，不要使用网页上的展示昵称。
- **视觉模型**：必须支持 `image_url` 的 PNG Base64 图片输入。留空时使用文字模型；文字模型如果不支持图片，框选请求会失败。两个模型使用相同的 API 地址和密钥。
- **翻译偏好**：可填写语气、术语或格式要求。

远程接口必须使用 HTTPS。本机服务可使用 `http://localhost:端口/v1` 或 `http://127.0.0.1:端口/v1`。软件不会自动跟随 API 重定向；如有重定向，请填写最终地址。网络请求最长等待 90 秒，可以取消手动请求，关闭小浮窗也会取消对应请求。

软件不附带 API 密钥，不提供内置免费翻译额度。所有请求均由你配置的服务处理并计费。

## 快捷键与毛玻璃

在设置页点击快捷键输入框，然后直接按新组合键。组合键需包含 Ctrl、Alt 或 Win，以及一个普通按键。两个组合不能相同；如果被其他软件或系统占用，保存时会给出提示并尝试恢复旧组合。

在 **外观** 中切换毛玻璃，并拖动透明度滑块实时预览，点击 **保存并应用** 后持久保存。主窗口与翻译小浮窗同步使用系统 Acrylic 毛玻璃，文字和按钮保持清晰。小浮窗有独立的明亮白色底色，避免深色桌面或系统材质使背景显得灰暗。

原生 Acrylic 使用 Windows 11 22H2（系统版本 22621）及以上提供的 DWM 接口。较早版本会自动使用不透明浅色背景。Windows 自身的透明效果、节能或远程桌面设置也可能影响系统材质的显示。

## 本地数据

配置与翻译记录保存在 `%LOCALAPPDATA%\FloatTranslate`：

- `settings.json`：配置。密钥通过 Windows DPAPI 加密，仅当前 Windows 用户可解密。
- `history.json`：最多 100 条翻译记录，包含原文和译文，不含截图。可关闭记录保存，也可以在历史页清空已有记录。

除了向配置的 API 发出请求，软件没有分析、遥测或上传历史记录的服务。启动时不会自行发送模型请求。

## 运行环境与源码

支持 Windows 10/11 x64，使用系统的 .NET Framework 4.8；毛玻璃需要上文所列的新版本 Windows。请保留 `FloatTranslate.exe.config` 与 EXE 在同一文件夹。

包内包含全部 C# / WPF 源码和 `build.ps1`，不依赖 NuGet 包、Electron、浏览器运行时或 Python。修改后，在此文件夹运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

启用登录自启动后，请保留当前 EXE 的位置；移动程序后重新关闭并开启该选项，以更新启动路径。

命令行辅助选项：`--settings` 打开设置；`--background` 进入托盘；`--preview 目录` 生成带有明确示例标记的界面预览；`--self-test 报告路径` 执行本地测试；`--ui-test 报告路径` 执行隐藏的 WPF 流程测试。

## 验证范围

已用本地模拟 API 验证文本和 PNG 图片请求、鉴权、错误提示、响应解析、取消请求、真实界面按钮流程、记录保存，以及 Windows 全局快捷键注册。密钥加密在正常 Windows 用户环境下进行了写入和解密验证。实际服务的模型能力、额度与响应时间，需要填写你的配置后测试连接确认。未对所有第三方程序逐一验证划词或截图行为。

界面预览中的译文是显示效果样例，彩色柔化背景用于展示透明层次；实际运行时由 Windows 合成桌面背景的模糊效果。
